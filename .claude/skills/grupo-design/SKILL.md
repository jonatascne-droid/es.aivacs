# Grupo: Design

## Qual skill usar

| Pedido | Skill principal | Apoio |
|---|---|---|
| Peça estática (post, pôster, banner) na identidade AIVACS | `aivacs-estudio` (`scripts/lib.py`, `style.css`) | `canvas-design` |
| Imagem gerada ou editada com IA | `image` | `aivacs-estudio/scripts/gem_imagem.py` |
| Interface ou landing com cara profissional | `frontend-design`, `ui-ux-pro-max` | `impeccable` (polir, tipografia, layout) |
| Revisar a qualidade de um design | `design:design-critique`, `impeccable` (`/impeccable critique`, `audit`) | `design:accessibility-review` |
| Animação de interface (site, app) | `animate` | `emil-design-eng`, `improve-animations`, `review-animations`, `find-animation-opportunities` |
| App web com cara de app nativo no celular | `mobile-native` | |
| Testar a interface com dados extremos | `break-ui` | |
| Sistema de design, entrega para desenvolvimento | `design:design-system`, `design:design-handoff` | |
| Textos de interface | `design:ux-copy` | |
| Tom de voz da marca | `brand-voice:brand-voice-enforcement` | |
| Página para mostrar ao Jhony | ferramenta Artifact | `artifact-design` |

## Regras da casa

- Identidade AIVACS em `aivacs-estudio/references/identidade.md`: fundo escuro, azul `#4BBFEF`, Plus Jakarta Sans, DM Sans, JetBrains Mono, logo do triângulo. Não sair dela; para cliente, a marca dele.
- Antes de entregar uma peça, renderize e olhe: alinhamento, margens, texto cortado, sobreposição, hierarquia e um destaque por peça.
